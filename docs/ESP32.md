# Гирлянда JH-CLD-01 на ESP32 + WLED

Цель: попиксельное управление 200 светодиодами по Wi‑Fi, затем карта камерой и эффекты по
форме. Родной BLE-контроллер остаётся на месте как источник питания 5 В; меняется только
источник сигнала на линии DAT.

## Что известно и что нет

| Известно | Не проверено |
|---|---|
| На плате контроллера выводы подписаны `5V`, `DAT`, `GND` | протокол линии DAT (WS2812B / WS2811 / другой) |
| Серийная адресуемая гирлянда, по одной микросхеме на LED, 200 шт. | уровень сигнала: хватит ли 3,3 В с ESP32 |
| Питание всей системы — USB-A родного контроллера | ток гирлянды при полном белом |
| ESP32 DevKit USB-C, WLED 16.0.1, имя `wled-5de7f8`, был IP 192.168.1.166 | выбранный GPIO18 (D18) ещё не использовался |

## Схема подключения (вариант A — питание от родной платы)

```
Родная плата          Гирлянда                  ESP32 DevKit
 5V  ─────────────────  5V
 GND ────┬────────────  GND
         └─────────────────────────────────────  GND   (общая земля обязательна!)
 DAT  ✂ (разорвать)     DAT ──[330 Ом]─────────  GPIO18 (D18)
                                                 USB-C ← своё питание
```

- Разрывается **только** DAT между платой и гирляндой; 5V и GND остаются.
- Резистор 220–470 Ом последовательно в DAT — защита первого светодиода; можно без него на первое
  включение.
- Родной контроллер при этом будет «думать», что управляет гирляндой, — это не мешает.
- Если первый LED мерцает или цвета мусорные при верном типе — нужен сдвиг уровня 3,3→5 В:
  74AHCT125 / 74HCT245, либо «жертвенный» пиксель, запитанный от ~4,3 В (диод в его 5V).

## Настройка WLED

1. Открыть `http://wled-5de7f8.local` (или IP из роутера).
2. Config → **LED Preferences**:
   - LED outputs: **1**, тип **WS281x** (сначала), Color Order **RGB** (у нашего экземпляра RGB),
     Start 0, Length **200**, GPIO **18**.
   - Maximum PSU current: 1000 mA (WLED сам ограничит яркость), позже уточним.
   - Save & Reboot.
3. На главном экране WLED: яркость ~30 %, цвет красный → **Solid**.

## Протокол проверки

1. Длина = **1** в WLED, красный. Горит только первый LED красным? Если жёлтый/зелёный — порядок
   каналов, менять Color Order. Если мусор/мигание — другой тип чипа.
2. Длина = 200, красный. Вся лента ровно красная без «снега»?
3. Эффект **Rainbow** / **Chase** — бежит ровно по всей длине, без сбоев в конце?
4. Полный белый на 100 % — греется ли USB-кабель/плата, падает ли яркость к концу ленты.

Перебор типов, если WS2812B не подошёл: WS2811 (400 kHz) → SK6812 → TM1814 → UCS8903 →
GS8208 → SM16825. На каждом — шаг 1.

## Что даст успех

- WLED JSON/UDP-реалтайм (DDP) — 200 LED при 30+ fps с телефона: наше приложение станет
  клиентом WLED по Wi‑Fi (второй транспорт рядом с BLE).
- Карта камерой: зажигаем по одному LED через DDP, снимаем, вычитаем кадры → `index → x,y`.
- Эффекты по форме: градиент, волна, рисование — считаются на телефоне, уходят в DDP.

## Результат (24.10.2026) — попиксельное управление ПОДТВЕРЖДЕНО

- Первая запасная ESP32 (MAC 88:57:21:e0:ae:c8) прошита WLED 16.0.1 с Mac (esptool, бутлоадер
  `bootloader_esp32_8m.bin` @0x1000, разделы `partitions_c3_4m.bin` @0x8000, `boot_app0.bin` @0xE000,
  приложение @0x10000). WLED загрузился, но Wi‑Fi-радио платы мёртвое: три скана по Improv — 0 сетей,
  точка доступа не видна. Плата отбракована.
- Вторая ESP32 — это и есть `wled-5de7f8` (MAC 80:f3:da:5d:e7:f8), WLED 16.0.1, уже в сети
  `192.168.1.166`, канал 1 (2,4 ГГц), RSSI −49.
- Гирлянда подключена: 5V → VIN, GND → GND, DAT → 220 Ом → GPIO18. Питание всей системы — USB-C платы.
- Конфигурация WLED (`/json/cfg` → `hw.led.ins[0]`): `type 22` (WS281x), `pin [18]`, `len 200`,
  **`order 1` = RGB** (0 в WLED означает GRB — при нём оранжевый выглядел зелёным), `maxpwr 1000` мА.
- Проверено на гирлянде: сплошной красный — все 200 ровно, без «снега»; попиксельно через
  `{"seg":{"i":[0,[255,0,0],5,[0,0,255],10,[0,255,0],199,[255,255,255]]}}` — горят ровно LED 1, 6, 11
  и 200 своими цветами. **Критерий первого этапа выполнен.**
- DDP (UDP 4048) с Mac: 40 fps стабильно, WLED отчитывается `fps 41`, `lm DDP`. Один пакет на кадр
  (600 байт).

Итого: протокол ленты — WS281x-совместимый (WS2812-тайминги), порядок каналов RGB, 200 адресуемых
пикселей, 3,3 В с GPIO хватает через 220 Ом без сдвига уровня.

## Второй этап: карта камерой (24.10.2026, ночь)

- Приложение подключается к WLED по IP (Bonjour на iPhone нашёл `wled-5de7f8`, но автоподключение
  надёжнее по сохранённому адресу). Первый запуск: UDP-сокет DDP падал с ошибкой 57, пока iOS
  показывала запрос «локальная сеть» — добавлен автоперезапуск сокета.
- Важная особенность WLED: после попиксельной команды (`seg.i`) сегмент **замораживается** (`frz`),
  и сплошной цвет/эффекты не применяются, пока не послать `"frz": false`. Учтено в `setSolid`.
- Гирлянда развешена змейкой на двери, телефон напротив; первый скан дал осмысленную карту:
  вертикальные нитки видны, «Волна» идёт по карте. Есть кучка выбросов слева (блики или
  дрожание камеры) — нужен фильтр выбросов и повторный проход по ненайденным.

## Карта внутри WLED: автономные 2D-эффекты (24.10.2026)

Проверено на `wled-5de7f8` (WLED 16.0.1):

- Загрузка файла: `POST /upload`, multipart поле `data`, имя файла `/ledmap.json`; ответ `File Uploaded!`.
- Формат: `{"width":W,"height":H,"map":[…]}` — W×H значений, индекс LED или `-1` для пустой ячейки,
  без пробелов (парсер чувствителен).
- Активация без перезагрузки: `POST /json/state {"ledmap":0}` → `/json/info` сразу отдаёт
  `leds.matrix {w,h}` даже без настройки панелей. Для надёжности после этого записывается
  `hw.led.matrix {mpc:1, panels:[{w,h}]}` в cfg.
- В прошивке 62 эффекта с поддержкой 2D (флаг `2` в 4-м поле `/json/fxdata`), из них 40 чисто
  двумерных: Drift 164, Waverly 165, Plasma Ball 178, Polar Lights 174, Noise2D 146, DNA 152,
  PS Fire 188, PS Waterfall 196, Blobs 121, Lissajous 176, Game Of Life 172 и т. д.
- Приложение: `LedmapExport.grid(from:)` подбирает сетку (минимальная высота, при которой ≥97 %
  пригодных LED получают свою ячейку, занятые ячейки — в 8 соседей, ≤2048 ячеек), экран WLED →
  «Загрузить карту в WLED» → раздел «2D-эффекты WLED» (подборка, скорость, детали, яркость, палитра).

## Грабли: карта 2D меняет адресацию (25.10.2026)

Пока в WLED активна `ledmap.json` с width/height, **номер пикселя в JSON (`seg.i`) и в DDP — это
ячейка сетки**, а не физический LED: `leds.count` становится w×h (было 378), «зажечь №1» зажигает
LED из ячейки 0, пустые ячейки не зажигают ничего, LED вне карты не управляются вовсе. Симптом:
после перевешивания «не все горят», тест 1·6·11 зажигает 3-й и ~40-й.

Поэтому перед сканированием и попиксельными тестами нужен **прямой режим**: загрузить
`{"map":[0,…,199]}` (1D-тождество), `hw.led.matrix.mpc=0`, затем `{"rb":true}` — без перезагрузки
WLED держит прежний размер матрицы. Удаление файла через `/edit` в этой сборке недоступно (404),
тождественная карта его заменяет. Переход прямой → 2D перезагрузки не требует (`{"ledmap":0}`).
В приложении: `WLEDClient.addressingMode`, `setDirectMode()`; экран скана переводит WLED в прямой
режим сам (~15 с), экран WLED показывает текущую адресацию и кнопку «Снять карту».

## Грабли №2: сегмент в 2D задаётся прямоугольником (24.10.2026, вечер)

После загрузки карты сегмент 0 остаётся одномерным `start 0 / stop 200`. В матрице 13×18 это
обрезанная область — эффекты «только в середине», «моргают», часть не рисует вовсе (видео 1–4).
Правильно: `{"seg":[{"id":0,"start":0,"stop":W,"startY":0,"stopY":H}]}`. Теперь `WLEDClient`
шлёт геометрию под текущий режим во всех командах (`fullSegment`), а в 2D-режиме переводит
DDP-кадры и `seg.i` из номеров LED в ячейки по сохранённой сетке (`currentGrid`, UserDefaults).
Скан окна «занавесом»: 200/200 найдено, сетка 13×18, 196 в ячейках.

## Что умеет приложение к концу 24.10.2026

- **HomeView** (WLED-first): питание, яркость, живое превью по WS, 16 эффектов с палитрами, сцены.
- **Конструктор** (телефон, DDP): перелив, полосы, градиент, спираль, кольца, плазма; цвета (до 5),
  угол, скорость, масштаб, изгиб, мягкость, искры; сохранение в сцены (`LightScene.constructor`).
- **Расписание** (WLED): NTP включается кнопкой (`if.ntp.en`, tz 2), пресеты сцен → `psave` 1…40,
  «Выключить» → пресет 201, плейлист → пресет 200 (`playlist.ps/dur/transition`), таймеры
  `timers.ins[0..1]` (включить вечером / выключить ночью).
- **Текст** (WLED fx 122 Scrolling Text, `seg.n`), транслит кириллицы; нужен 2D-режим.
- **Раскладка**: поворот/отражение карты (`LEDMap.transformed`), после — заново загрузить в WLED.
- **Ёлка**: `TreeScan.merge` — fit оси/высоты/радиуса по силуэту каждого ракурса,
  φ = θ_k + asin(dx / R(h)), выбор ракурса с лучшим score = confidence·(1 − 0.7|dx|), высота —
  взвешенное среднее; выход — развёртка `cylindrical = true`, `cameraAspect = 2`. Инструкция:
  четыре стороны, каждый раз четверть круга ВПРАВО (если смотреть на ёлку).
