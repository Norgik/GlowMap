# Как снять BLE-трафик приложения LED LAMP

Цель: увидеть кадры, которые LED LAMP реально отправляет в FFE1 нашей гирлянде в режимах,
которых нет в открытых реализациях (настройки «чип / число LED», graffiti/текст, если они
доступны для LEDDMX-00). Трафик — это факты, в отличие от декомпиляции.

## Вариант A — Android (проще всего)

1. Настройки → О телефоне → 7 раз по «Номер сборки» → появятся «Для разработчиков».
2. Для разработчиков → **«Журнал Bluetooth HCI»** (Enable Bluetooth HCI snoop log) → включить.
3. Выключить и включить Bluetooth.
4. Открыть LED LAMP, подключиться к `LEDDMX-00-698A`, выполнить интересующие действия
   **медленно и по одному**, записывая время каждого (например: 12:03 — включил, 12:04 —
   красный, 12:05 — зашёл в настройки чипа, поставил 200 LED, 12:06 — graffiti…).
5. На Mac: `adb bugreport ~/Desktop/bugreport.zip` (нужен включённый USB-отладчик).
   Внутри архива: `FS/data/misc/bluetooth/logs/btsnoop_hci.log`.
6. Открыть `btsnoop_hci.log` в Wireshark, фильтр:
   `btatt.opcode == 0x52 || btatt.opcode == 0x12` (Write Command / Write Request).
   В колонке Value — наши 9-байтовые кадры. Или просто прислать файл мне.

## Вариант B — iPhone

1. На Mac войти на <https://developer.apple.com/bug-reporting/profiles-and-logs/> →
   **Bluetooth for iOS** → скачать профиль `BluetoothLogging.mobileconfig` (нужен Apple ID,
   платный аккаунт не обязателен).
2. Передать профиль на iPhone (AirDrop) → Настройки → Профиль загружен → Установить.
   Перезагрузить iPhone.
3. Выполнить действия в LED LAMP так же, по одному, с записью времени.
4. Сразу после — снять **sysdiagnose**: одновременно зажать обе кнопки громкости и боковую
   на ~1,5 с (короткая вибрация). Через 10 минут файл появится в
   Настройки → Конфиденциальность → Аналитика → Данные аналитики → `sysdiagnose_…tar.gz`.
   Поделиться → AirDrop на Mac.
5. В архиве: `.../bluetooth/…/*.pklg`. Открыть в **PacketLogger** (Xcode → Open Developer Tool →
   More Developer Tools → Additional Tools for Xcode → Hardware/PacketLogger) или в Wireshark.
6. Фильтр тот же: ATT Write к handle характеристики FFE1.

## Что именно сделать в LED LAMP во время записи

1. Подключиться, включить, выключить, включить.
2. Задать красный, зелёный, синий (сверка с известным кадром `7B FF 07 …`).
3. Настройки устройства → выбор чипа / порядок RGB / число LED → сохранить (это кадр `05`).
4. Если доступна вкладка graffiti / «тuya» / текст / рисование — нарисовать одну точку,
   затем две разного цвета. Это главное.
5. DIY-режим: добавить 2 цвета, запустить, переключить режимы.
6. Любые пункты меню, которых нет в нашем приложении: таймер, музыка, скорость.

Если вкладки graffiti для LEDDMX-00 в LED LAMP нет — это само по себе важный результат:
значит, производитель не считает эту гирлянду матричной, и кадры `7C…CF` можно только
пробовать вслепую (они всё равно добавлены в лабораторию).
